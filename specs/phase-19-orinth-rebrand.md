# Phase 19 — Orinth rebrand, auth-first entry, documentation removal

## Goal

Three changes that land together because they all rewrite the app's front door:

1. **Rebrand.** The product is **Orinth**, by **Onestep AI Labs** — replacing "Onestep AI Platform"
   and the "ONESTEP" parent lockup. The visual system is unchanged: same tokens, same density, same
   typography. Only the name and the mark move.
2. **Auth is the first page.** `/` is the sign-in screen. The marketing landing page is deleted, not
   relocated — a public marketing surface belongs on the Orinth site, not inside the app.
3. **No in-app documentation.** The `/documentation` route, its sidebar entry, and its markdown corpus
   are removed.

## Non-Goals

- No change to the design system. Tokens, elevation, spacing, and component behavior are untouched;
  this is not a redesign.
- No auth backend. Sign-in stays presentational, and its notice still says so. `docs/ai/rules.md`
  still governs when real auth lands.
- ~~No repo rename.~~ Superseded immediately after this phase merged: the repository was renamed to
  `orinth` and transferred to the `Onestep-AI-Labs` organization, the local checkout moved to
  `AI/Orinth/orinth`, and the local skill was renamed `orinth` (`$orinth`). GitHub redirects the old
  URLs, but remotes were repointed explicitly rather than relying on them.
- No replacement for the deleted documentation. Reintroducing a docs surface needs its own spec.

## Brand

| | Before | After |
|---|---|---|
| Product name | Onestep AI Platform | Orinth |
| Parent | ONESTEP | Onestep AI Labs |
| Sidebar sub-label | AI research workspace | The local AI studio |
| Sidebar footer | ONESTEP product studio | By Onestep AI Labs |
| Mark | `logo_transparent.png` (raster, one tone) | `LogoMark` SVG on `currentColor` |

The mark is a path turning through a rounded frame — "orient" plus the *-inth* of *labyrinth*. It is
stroked rather than filled so it survives favicon size, and it takes `currentColor` so one asset
serves the sidebar, the sign-in screen, and both themes without a light/dark pair.

`frontend/components/brand.tsx` is the single source: `LogoMark`, `BRAND_NAME`, `BRAND_TAGLINE`,
`BRAND_PARENT`. Nothing else may retype the name or ship a second logo file.
`frontend/public/brand/orinth-mark.svg` is the standalone tile for the favicon and for README and
presentation placements, where `currentColor` has nothing to inherit from.

The old `logo_dark.png` / `logo_light.png` / `logo_transparent.png` are deleted — they are the
previous product's mark and no longer represent anything shipping.

## Routes

| Before | After |
|---|---|
| `app/(marketing)/page.tsx` → landing | deleted |
| `app/(marketing)/signin/page.tsx` → sign-in | `app/(auth)/page.tsx` → sign-in, at `/` |
| `app/(platform)/documentation/**` | deleted |

- Route group `(marketing)` → `(auth)`. The group renders no shell and no project context, exactly as
  before; only its name and its contents change.
- `features/marketing/` → `features/auth/`; `signin-page.tsx` → `auth-page.tsx`.
- `app/styles/marketing.css` → `app/styles/auth.css`, pruned to the sign-in rules.
- `features/auth/routes.ts` drops `LANDING_HREF`. `SIGN_IN_HREF` is now `"/"`; `WORKSPACE_HREF` is
  unchanged at `/projects`.
- The sign-in screen's "Back" link is gone — there is nothing behind `/` to go back to. Its place is
  taken by the wordmark, which identifies the product and does not navigate.

The desktop app already opened on the sign-in route rather than the landing page
(`specs/phase-18-macos-desktop-app.md`), so it now opens on `/` and needs no behavior change beyond
the URL.

## Design system deltas

Landing-only tokens are deleted, because the surface that justified them is gone:
`--display-hero`, `--display-stage`, `--hero-tracking`, `--landing-gap`, `--landing-measure`,
`--landing-max`. `--display-section` survives — the sign-in heading uses it, and it remains the only
sanctioned step past the app's 24px ceiling.

`frontend/DESIGN.md` §10 is rewritten from "Landing scope — `/` and `/signin` only" to
"Auth scope — `/` only", and §9 gains a rule against reintroducing a marketing page.

## Identifiers

Renamed (user-visible or product-identifying):

- macOS bundle: `productName` → `Orinth`, `identifier` → `orinth.ai.studio`, and `paths.rs::APP_ID`
  to match.
- Rust crate `onestep-desktop` → `orinth-desktop` (lib `orinth_desktop`), window titles, supervisor
  owner tag, and the `ORINTH_DESKTOP` child env var.
- Package names `orinth-frontend`, `orinth-desktop`, `orinth-backend`; backend `Settings.app_name`.
- The header emitted into generated architecture code: `# Generated by Orinth from architecture …`.

**Deliberately not renamed**, because the identifier is load-bearing for data written before the
rename:

- `register_keras_serializable(package="onestep")` — baked into every saved Keras model; changing it
  breaks deserialization of existing models.
- `localStorage["onestep-tours-seen"]`, `localStorage["image-platform-project"]` — renaming would
  silently reset a user's tour and project state.
- `"onestep.architecture.clipboard/v1"` — renaming would break pasting anything copied before the
  rename.

### `orinth.ai.studio` and existing installs

The bundle identifier determines the app-data root, so an existing install's
`~/Library/Application Support/ai.onestep.platform/` is no longer read. Its contents — provisioned
runtimes, the SQLite DB, datasets, models, storage — are still on disk but orphaned; the rebranded app
provisions a fresh `~/Library/Application Support/orinth.ai.studio/` on first launch, which means
re-downloading the ~2.7 GB ML environment. This was an explicit decision, not a side effect. There is
no migration step; anyone who needs the old data can move the directory by hand.

## Acceptance Criteria

- Visiting `/` renders the sign-in screen. No route renders a marketing landing page.
- Submitting sign-in still lands on `/projects`.
- `/documentation` and `/documentation/{slug}` 404. The global sidebar shows Projects and Settings
  only, and the workspace tour runs without a documentation step.
- The sidebar, sign-in screen, browser tab, desktop window title, and macOS bundle all read "Orinth".
- No `Image`-based logo remains in the app; the mark renders from `LogoMark` and inherits ink from
  its surface in both themes.
- No source file outside the exclusions above contains "Onestep AI Platform".
- `pnpm typecheck`, `pnpm lint`, `pnpm build`, and `uv run pytest` all pass.

# Specs

Specs are the planning and execution reference for AI agents.

Use a spec when:

- adding a feature,
- changing API behavior,
- changing ML model behavior,
- changing testing/training workflows,
- changing persistence or storage behavior.

## Spec Lifecycle

1. Create or update a spec before implementation.
2. Mark unresolved decisions explicitly.
3. Implement against the spec.
4. Update the spec if implementation changes the plan.
5. Record validation commands in the spec or final response.

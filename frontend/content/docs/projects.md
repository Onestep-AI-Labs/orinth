# Workspace & Projects

The Onestep AI Platform is designed around a project-scoped workspace. Every experiment, dataset, and trained model is organized under a specific project, ensuring your team's work remains structured and understandable.

![Project List](/brand/1_project_list.png)

## Core Capabilities

- **Unified Workspace:** A default research project is created automatically for existing data. You can easily switch active projects directly from the workspace UI.
- **Task-Driven Scoping:** Each project is created with specific task types in mind (e.g., Image Classification, Object Detection, NLP Summarization). This restricts dataset uploads and model training to relevant tasks only, minimizing clutter and preventing task mismatches.
- **Clear Provenance:** All datasets, models, splits, and training artifacts are explicitly tied to the project, meaning there is never any ambiguity about which data was used to train a specific model.

## UI Principles

- **Operational First:** The first screen you see is the project list, prioritizing scanning, comparison, and action.
- **Local Trust:** The platform serves as a local research/engineering tool. Uploads, predictions, and runtime artifacts are strictly kept under local ignored storage.
